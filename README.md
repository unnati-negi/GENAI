# GenAI Healthcare Case Study

This project demonstrates the use of **Hidden Markov Models (HMM)** for analyzing healthcare patient states and predicting possible health conditions over time.

---

## 📌 Project Overview
The goal of this project is to model patient health progression using probabilistic models.  
Hidden Markov Models help identify **hidden health states** based on observed patient data.

Example health states:
- Healthy
- At Risk
- Critical

The model learns transition probabilities between these states and predicts the most likely hidden state sequence.

## 📊 Dataset
The dataset contains healthcare information such as:
- Age

- Other medical attributes

These observations are used to estimate hidden patient health states.

## ⚙ Methodology
1. Data preprocessing  
2. Defining hidden states and observations  
3. Training the Hidden Markov Model  
4. Predicting hidden health states  
5. Visualizing state transitions  

---

## 📈 Results
The HMM model identifies patterns in patient data and predicts hidden health conditions that are not directly observable.
